# A LED that blinks Morse code. Made with Rust and virtual ESP32-C3 microcontroller. :crab:


Rust in embedded systems exercise.

The goal of this exercise was to create a simple program in Rust, which sparked my interest in exploring embedded systems. 
Wokwi.com provided suitable virtual microcontrollers for this purpose. 
I aimed to keep the hardware simple, focusing on functionality instead.
Translating text into Morse code felt like a suitable exercise in terms of coding Rust.
The final result is a program that uses a LED to blink the message "Hello World" in Morse code.
